# Laminar - Issue & Bug Tracker

Welcome! This repository serves as the public space to report bugs, discuss hardware compatibility, and suggest features for the Laminar Engine Minecraft mod.

As mentioned on the Modrinth page, Laminar is a solo experiment. The source code is closed-source and kept in a private repository simply because I thought you guys wouldn't want to see the code, and honestly, I thought so too. You will not find any code here—this space is purely for community feedback and issue tracking.

---

## Where to Download

You can grab the latest compiled releases of Laminar exclusively on Modrinth:
- [Modrinth Project Page](https://modrinth.com/mod/laminar-engine)

---

## How to Help Me Fix Things

Since I work on this project alone during my free time, detailed bug reports help me immensely. If you run into problems, please try to include the following when opening an issue:

1. **Check Existing Issues:** A quick search might show if someone else has already reported the same problem.
2. **Provide Logs & Crash Reports:** If your game crashed, please share the `latest.log` or the crash report. Instead of pasting massive walls of text directly, using services like [mclo.gs](https://mclo.gs/) or [Pastebin](https://pastebin.com/) makes it much easier to read.
3. **Hardware Specs:** Laminar relies heavily on hardware interactions. Please tell me your CPU, dedicated GPU (if you have one), and your integrated GPU (iGPU) models.
4. **Mod List:** Let me know what other optimization or rendering mods you are currently running (like Sodium, Lithium, VulkanMod, etc.).
5. **Steps to Reproduce:** Explain clearly what you did before the bug happened so I can try to trigger it on my end.

---

## A Note on Conduct

Let's keep things chill and constructive. I am always open to technical discussions and hardware testing feedback, but please remember that this is a free, personal project. 

Please keep the tone respectful. Any spam, off-topic arguments, or toxic behavior will result in the thread being closed and locked.
