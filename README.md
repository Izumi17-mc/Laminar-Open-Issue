# Laminar - Official Issue Tracker & Bug Tracker

This repository is the official public tracker for bug reports, compatibility issues, and feature requests for the **Laminar Engine** Minecraft optimization mod. 

The source code of Laminar is proprietary (All Rights Reserved) and is hosted in a private repository. This repository contains no source code.

## How to Report a Bug

To help us diagnose and resolve issues efficiently, please follow these guidelines when opening a new issue:

1. **Check Existing Issues:** Search the active and closed issues before opening a new thread to avoid duplicate reports.
2. **Provide Logs & Crash Reports:** If the game crashed, attach the complete crash report (found in `.minecraft/logs`) or the `latest.log`. Use text-sharing services like [mclo.gs](https://mclo.gs/) or [Pastebin](https://pastebin.com/) to upload long logs.
3. **Provide System Specifications:** List your CPU model, dedicated GPU (if any), and integrated GPU (iGPU) model.
4. **List Active Modifications:** State the other rendering and optimization mods currently installed (e.g., Sodium, Lithium, VulkanMod).
5. **Steps to Reproduce:** Explain clearly how to trigger the bug.

## Code of Conduct

This issue tracker is strictly for constructive technical feedback, bug reports, and development coordination. 
- Please maintain a respectful and professional tone.
- Low-effort, spam, off-topic, or toxic threads will be closed and locked immediately.
